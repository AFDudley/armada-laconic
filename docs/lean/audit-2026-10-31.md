## 2. Tooling findings

1. The first `facts.json` was wrong for every theorem: `ConstantInfo.value?` returns `none` for theorems unless
   `allowOpaque := true` (found by AuditNitroLiveness; fixed and regenerated; 14 `sorry` now matches `check.sh`).
2. "Proof term names a base operation" over-counts: a proof that uses a per-call lemma names the operation through
   that lemma's type. Violation lists above come from reading. `layerDiscipline` must detect unfolding
   (`type-doctrine.md` §4a).
3. Select declarations by module, not namespace: Pool theorems sit at the root namespace (`type-doctrine.md` §1).
4. Copying `.lake/build` between worktrees on different branches is unsafe: a copied build failed with
   `Unknown identifier IsLedgerChannel` (another branch's compiled files). A clean build of the trunk takes 56 s.
   Briefs must not tell agents to copy builds.
