# engineering/ — notes for agents

The `.md` files here are the source of truth; every `.html` beside them is generated by `tools/render-engineering.sh`. Never hand-edit an `.html` file. After changing any `.md`, regenerate:

```bash
MARKDOWN=~/.local/bin/markdown_py SED=/usr/bin/sed tools/render-engineering.sh
```

## Architecture decisions (ADRs)

Decisions live in `09-architecture-decisions.md`. The current, compiled view is `09a-current-decisions.md`, generated from it by `tools/compile-decisions.py`. Read `09a` to learn what is decided now; read `09` for why. The rules and their justifications are in `decision-records.md`. In short:

- **A Decision is numbered clauses**: `- **D11.3** <one decision>`, numbered from 1 within each ADR. Only Decision clauses are normative; Context, Consequences and Alternatives are prose.
- **Never edit an accepted ADR's decision text.** To change a decision, write a new ADR whose clause names what it replaces: `- **D17.6** (supersedes D11.3) <text>`.
- **A superseding clause restates whatever of the old clause still holds.** A clause is wholly live or wholly superseded. The checker cannot verify this; a reviewer must. (D17.1 first superseded D11.3 without restating "v1 yield is ETH/wstETH only", and the compiled view silently lost that rule.)
- **No pointer prose.** Don't write "amended by" or "amends" in status lines or the index; the `(supersedes …)` marker is the only record. Statuses are `proposed`, `accepted` or `withdrawn`, plus a release tag such as `v1.5`.
- **Only accepted ADRs count.** A proposed ADR's supersessions show as pending in `09a`.

After editing `09-architecture-decisions.md`:

```bash
python3 tools/compile-decisions.py          # regenerate 09a-current-decisions.md
python3 tools/compile-decisions.py --check  # what the pre-commit hook runs
```

The pre-commit hook fails the commit if clause IDs are malformed, duplicated or out of sequence, a supersede target is missing or not in an earlier ADR, a clause is superseded twice, an index status disagrees with its ADR, or `09a` is stale.
