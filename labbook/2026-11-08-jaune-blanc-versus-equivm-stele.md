# Jaune/Blanc against EquiVM/Stele, measured (2026-11-08)

## Question

On 2026-11-08 the operator asked why EquiVM was chosen and Jaune was not, and how to check whether Jaune is better.
EquiVM was chosen on 2026-10-22 from a web search for "Lean 4 to Solidity" work. Jaune and Blanc (`skbaek/jaune`,
`skbaek/blanc`, EVM semantics and bytecode proofs in Lean 4, MIT, one author) were not in the search results, so they
were missed, not rejected (sessions `01a15aed`, `01a156a6`).

## Method

Checks V1-V6. Every run after V1-V4 used one container image, `localhost/jaune-eval:1`
(`.scratch/jaune-eval/env/Dockerfile`). The image is one layer on the evm-proof-toolchain worker image: pinned Python
crypto modules for EVMLean's precompile scripts, solc 0.8.20, and the Lake cache variables. Briefs and logs are in
`.scratch/jaune-eval/`.

V5 and V6 proved the same contract with each stack. The contract is `FeePool.sol`: four storage slots and
`setFeeRatio`, the fee-admin setter of the armada-lean pool. Its solc 0.8.20 runtime bytecode has sha256
`59144da4…72e288`, and both stacks proved that same bytecode.

## Reading

- **Speed.** EquiVM's generators make the scaffolding cost seconds, and the second run of the task was faster.
  Two causes are not separable from this one task [INFERENCE]: EquiVM proves no gas, and it trusts `native_decide`
  for the byte facts that Blanc proves in the kernel. Most of V5's 15 hours went to Blanc's literal gas form and
  Lean elaboration timeouts.
- **Strength.** Blanc proves three things that EquiVM does not state: existence of the successful run, exact gas,
  and a trust base of Lean's three axioms. The pool's liveness theorems (`*_can_happen`) need the first.
  `engineering/build-plan.md` already records the one-way EquiVM certificate as a gap. On this contract the gap is
  measured, not inferred.
- **Semantics.** Jaune passes the fixture set that EVMLean fails 141 times.

## Defects found

- Blanc: `rx_sload_sel` fails inside its own body (`ExactWalkCutOps.lean:156`, `simp made no progress`). Nothing in
  Blanc uses it.
- EquiVM: `scaffold.py` and `proof_skeleton.py` write one selector literal in two forms that are not syntactically
  equal, so the generated `Dispatch.lean` fails until `simpa` unfolds `UInt256.ofNat`.
- Lake: an absolute `packagesDir` is ignored without an error, so a project that shares built packages must use a
  relative path. With a relative path, V5's project rebuilt in 6.6 s instead of 38 min.
